Sobre esta Aplicação

1. Arquitetura MVT do Django

O Django segue o padrão MVT (Model, View, Template):

  • Model — define a estrutura dos dados e comunica com a base de dados através do ORM.
  • View — recebe os pedidos HTTP, consulta os modelos e devolve uma resposta (normalmente um template renderizado).
  • Template — ficheiro HTML que apresenta os dados ao utilizador.

Fluxo de informação: O browser faz um pedido → o Django verifica as URLs → chama a View correspondente → a View consulta o Model → passa os dados ao Template → devolve o HTML ao browser.

2. Modelação

Diagrama Entidade-Relação

Modelos em models.py


class Licenciatura(models.Model):
    nome = models.CharField(max_length=200)
    sigla = models.CharField(max_length=20)
    descricao = models.TextField()
    url = models.URLField()
    duracao_anos = models.IntegerField()

class Docente(models.Model):
    nome = models.CharField(max_length=200)
    url_pagina = models.URLField()
    foto = models.ImageField(upload_to='docentes/', blank=True, null=True)

class UnidadeCurricular(models.Model):
    nome = models.CharField(max_length=200)
    ano = models.IntegerField()
    semestre = models.IntegerField()
    descricao = models.TextField()
    imagem = models.ImageField(upload_to='ucs/', blank=True, null=True)
    ects = models.IntegerField()
    licenciatura = models.ForeignKey(Licenciatura, on_delete=models.CASCADE)
    docentes = models.ManyToManyField(Docente, blank=True)

class TipoTecnologia(models.Model):
    nome = models.CharField(max_length=50)

class Tecnologia(models.Model):
    nome = models.CharField(max_length=200)
    descricao = models.TextField()
    logo = models.ImageField(upload_to='tecnologias/', blank=True, null=True)
    url_website = models.URLField()
    nivel_interesse = models.IntegerField()
    tipo = models.ForeignKey(TipoTecnologia, on_delete=models.SET_NULL, null=True)

class Projeto(models.Model):
    nome = models.CharField(max_length=200)
    descricao = models.TextField()
    url_github = models.URLField()
    ano = models.IntegerField()
    unidade_curricular = models.ForeignKey(UnidadeCurricular, on_delete=models.CASCADE)
    tecnologias = models.ManyToManyField(Tecnologia, blank=True)
